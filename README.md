# MyLinux 32-bit OS

A lightweight, custom 32-bit Linux distribution built on **Debian Bookworm** using `live-build` and automated via GitHub Actions, tailored for legacy Intel Pentium and 32-bit hardware.

## Key Features
- **Ultra-Lightweight Desktop:** Powered by **Openbox** window manager, **Tint2** bottom panel, and **jgmenu** start menu.
- **Modern Dark UI:** Pre-configured with **Arc-Dark** GTK theme, **Papirus-Dark** icons, and a custom dark terminal profile.
- **Custom Bootloader:** Branded Isolinux boot menu with standard and failsafe video modes.
- **Built-in Applications:** Includes **Falkon** web browser, **PCManFM** file manager, **MPV** media player, **Mousepad**, and **Geany** IDE.
- **Developer Ready:** Comes with **Python 3** (`pip` 

## Automated Build
This ISO is built automatically in the cloud using the workflow defined in `.github/workflows/build.yml`.
